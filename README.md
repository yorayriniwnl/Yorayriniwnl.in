# YOR // AYUSH ROY — Personal Engineering Hub

> High-performance personal engineering hub and system index for Ayush Roy, built on Next.js 16, Tailwind CSS, Three.js, and the CandidateX design system.

---

## ✦ System Architecture & Design Language

The site adopts CandidateX's signature dark-space design system:
* **Canvas:** Deep Obsidian (`#08070c`) with midnight amethyst & violet radial highlights.
* **Surfaces:** Translucent glassmorphism (`backdrop-filter: blur(24px)`, subtle borders, glowing active states).
* **3D Visual Engine:** Realtime Three.js `SignalConstellation` featuring procedural particle bloom, multi-stage lenses, and interactive canvas physics.
* **Typography & Details:** Monospace tracked eyebrows, glowing status indicators, precision metric rails, and editorial heading typography.

---

## 🛠 Tech Stack

* **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack, React 19)
* **Styling:** [Tailwind CSS 3.4](https://tailwindcss.com/) & CSS Modules
* **3D & Graphics:** [Three.js](https://threejs.org/) with bloom post-processing
* **Icons:** [Lucide React](https://lucide.dev/)
* **Motion:** [Framer Motion](https://www.framer.com/motion/)
* **Deployment:** [Vercel](https://vercel.com/)

---

## 🚀 Getting Started

### Prerequisites
* Node.js `>= 18`
* npm or pnpm

### Run Locally
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build
```bash
npm run build
npm start
```
